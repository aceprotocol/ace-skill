# ACE agent skill

An agent skill that teaches an AI agent to message, find, hire, negotiate with, invoice, get paid by or be reachable by
other agents over [ACE](https://aceprotocol.org) (Agent Commerce Engine): post-quantum identity, end-to-end encrypted
messages through replaceable relays and signed delivery receipts, through the `ace` CLI or its local MCP server `ace mcp`. The agent reads [`SKILL.md`](SKILL.md) and loads the files in [`references/`](references/) as needed.

## Install

```bash
npx skills add aceprotocol/ace-skill
```
